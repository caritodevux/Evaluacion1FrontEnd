# Evaluacion1FrontEnd
## Descripcion del proyecto
Landing Page para un estudio de fotografia

## Problematica abordada
Se creara la página pensando en capturar nuevos clientes para sesiones fotograficas.

## Tecnologias usadas 
HTML, CSS, Bootstrap y GIT.

## Explicación breve del uso de la IA
Se usara GitHub Copilot para revisar y mejorar la estructura base, estilos, correión de errores y accesibilidad.
Se usara google gemini para generar texto en la sección < article >.
